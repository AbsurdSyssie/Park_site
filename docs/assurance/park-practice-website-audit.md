# Park Medical Centre website requirements evidence audit

This is a code-and-content evidence audit of the Park site against the reusable [practice website review checklist](../templates/practice-website-checklist.md). It records what the current source and a fresh local production render show. The source identifies England; the executed contract route remains unverified. This England GMS summary does not establish PMS, APMS or Wales applicability. It is not a legal opinion, an audit of the accuracy of practice facts, clinical assurance, accessibility conformance, DPO approval, or practice sign-off.

## Project-specific constraints checked

The production build and implementation checker support the approved route map: all 49 mapped routes rendered; the checker found the agreed six primary labels in order, five overflow destinations, all 82 mapped contextual edges, and breadcrumb chains matching the plan. The generated site retained the standalone `/urgent-help/` route, and the review report records the shared urgent-help panel on Home and Appointments only. The same report records the CQC footer widget and urgent-help footer link as retained. These are implementation checks for the documented project decisions, not clinical safety resolution or approval to alter navigation/content.

The review plan preserves existing public URLs, source content, the six primary navigation labels and order, and the CQC footer widget. It records no publication or practice sign-off. The home and appointments urgent-help placement does not resolve hazard H1; clinical safety assessment remains open. Existing public-content facts, GP earnings, privacy/DPO review, external destinations and clinical/source review remain pending.
