## Project-specific constraints checked

The original route-map baseline had 49 routes. After adding the partial leaflet, the production build and implementation checker were rerun against 50 mapped routes; the current verification results are recorded in the dated update above. The checker continues to require the agreed six primary labels in order and five overflow destinations. The generated site retained the standalone `/urgent-help/` route, and the review report records the shared urgent-help panel on Home and Appointments only. The same report records the CQC footer widget and urgent-help footer link as retained. These are implementation checks for the documented project decisions, not clinical safety resolution or approval to alter navigation/content.

The review plan preserves existing public URLs, source content, the six primary navigation labels and order, and the CQC footer widget. It records no publication or practice sign-off. The home and appointments urgent-help placement does not resolve hazard H1; clinical safety assessment remains open. Existing public-content facts, GP earnings, privacy/DPO review, external destinations and clinical/source review remain pending.
