# Park Medical Centre website requirements evidence audit

This is a code-and-content evidence audit of the Park site against the reusable [practice website review checklist](../templates/practice-website-checklist.md). It records what the current source and a fresh local production render show. The source identifies England; the executed contract route remains unverified. This England GMS summary does not establish PMS, APMS or Wales applicability. It is not a legal opinion, an audit of the accuracy of practice facts, clinical assurance, accessibility conformance, DPO approval, or practice sign-off.
